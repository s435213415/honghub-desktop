## 为什么客户端用不了

客户端影视仓的拉取逻辑（`kh-config.js` 的 `whFetchApply` → `parseWarehouseText`）只认两种内容：
1. 合法 JSON（含 `sites[]` 等）
2. base64 编码的上述 JSON

而这 6 条链返回的都是网盘网页 HTML，解析时会报「既不是合法 JSON，也不是 base64 编码的配置」。即使把网盘地址填进「＋添加仓」，也只会拉取失败。

## 网盘里的配置文件怎么拿到

网盘分享里通常是 `.txt` / `.json` 订阅配置文件。要让客户端可用，需要：
1. 在浏览器打开网盘链接 → 登录 → 保存到自己网盘 → 下载配置文件到本地；
2. 打开配置文件，把里面的 JSON 内容（或 base64 串）复制出来；
3. 客户端「网站」页 → 影视仓 → 「粘贴仓配置内容直接导入」文本框 → 粘贴 → 「导入到影视仓」。

这一步必须由本人在网盘网页完成登录/转存，程序无法绕过网盘的登录与验证码。

**关键结论**：
1. 网盘里装的是 785 MB 的 TVBox 应用压缩包，不是客户端能读的 JSON / base64 配置文件。即使下载解压，也需再取出里面的订阅地址，客户端无法直接消费。
2. 部分分享标题（「BL腐剧合集」「18影院-偷偷看」）指向成人 / 未授权影视内容。
3. 因此这批链接**不能**按「影视仓地址」或「网站入口」加入客户端，程序侧也没有绕过网盘登录下载 785 MB 包并解析订阅的意义与必要。

**可行的唯一路径**：若确实需要其中某个仓，请本人登录网盘下载解压，取出里面的**纯 JSON 订阅配置文本**（含 `sites[]` 的那种，通常几 KB），把文本内容发来，我可帮忙校验格式、整理成可粘贴导入的配置。
