这批地址和之前的采集接口不同，它们是 **TVBox 订阅配置地址**（一个地址里含几十上百个站点）。逐个跟踪后分成几类：

## 核心限制（务必看）

客户端**没有 TVBox 的爬虫运行环境**（Java 包 / drpy JS 引擎）。这些配置里 234+62+54 个站点中，绝大多数是 `key: csp_xxx` / `drpy_js_xxx` 形式，依赖爬虫包运行——客户端只能识别其中带 `http(s)` 直链的接口。

所以我做的事是：**展开全部配置 → 只提取 http 直链 → 逐个实测 → 只保留真能返回数据的**。

- 提取直链：**47 个**
- 实测可用：**25 个**
- 排除 JS 脚本 / 重复后：**21 个**（写入配置）

## 交付文件

`影视仓-资源地址-已验证.json` — 21 个已实测接口，按客户端影视仓格式整理（含 `name/api/type`）。

导入：客户端 →「网站」页 → 影视仓「粘贴仓配置内容直接导入」框 → 粘贴 → 导入。

## 两个提醒

1. **http 接口（天涯/非凡/建安）**：桌面 exe 可正常用；在线网页版是 https 页面，会被浏览器拦截混合内容，用不了。
2. **版权与稳定性**：这些接口来自第三方采集站，版权授权不明确、随时可能失效。客户端不托管任何内容，能否观看取决于对方站点。本配置仅供你本机自行导入，未写入客户端源码、未进入发布包。
