# 影视片单接入契约（sources-schema）

本文件是鸿汇影「自建/第三方影视资源」的接入契约。客户端不内置盗版源，任何进入片库的条目都必须符合本契约，并自带授权说明。

## 一、许可边界（硬性）

- 只接受：自有版权、已购买授权、或明确开放许可（CC-BY / CC0 / 公共领域）的内容。
- 不接受：未授权影视站、采集站（苹果CMS 等）接口、任何转发第三方正片的地址。
- 每条资源必须能说清「谁授权、什么许可」；说不清的条目不入库。

## 二、条目字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | 是 | string | 片单内唯一，建议 `ext_` 前缀 |
| `title` | 是 | string | 片名，最长 24 字 |
| `subtitle` | 否 | string | 副标题 / 来源说明，建议写明许可（如 `CC-BY 4.0`） |
| `category` | 是 | string | 必须是 `电影 / 动画 / 短剧 / 剧集 / 纪录片 / 综艺` 之一 |
| `year` | 否 | number | 年份 |
| `rating` | 否 | number | 0–10，仅作展示 |
| `tags` | 是 | string[] | 至少 1 个标签，建议含 `开放授权` 或 `自有授权` |
| `cast` | 否 | string | 出品方 / 作者 |
| `desc` | 否 | string | 简介，说明来源与许可 |
| `color` / `accent` | 否 | string | 卡片主色 / 描边色，十六进制 |
| `sources` | 是 | object[] | 1–3 条播放入口，见下 |

`sources[]` 每项：

| 字段 | 必填 | 说明 |
|---|---|---|
| `label` | 是 | 线路标签，如 `主源` / `官方镜像` / `备用` |
| `url` | 是 | `https` 直链，支持 `mp4` / `webm` / `m3u8`。`mkv` / `avi` / `iso` 浏览器无法流式播放，不接受 |

## 三、导入方式

1. 客户端「资源」页 → 「导入备份」，粘贴 JSON 数组，或先「导出备份」改完再导回。
2. 校验规则（代码内已实现）：`title` 必须是非空字符串，`sources` 必须是非空数组，全部通过才入库；不合规条目直接丢弃，不会写入。
3. 存储位置：本机 `localStorage.kh_vod_res`，上限 50 条，不上传、不共享。

## 四、示例

```json
[
  {
    "id": "ext_demo_1",
    "title": "示例短片",
    "subtitle": "自有授权 · 2026",
    "category": "动画",
    "year": 2026,
    "rating": 8.0,
    "tags": ["自有授权", "短片"],
    "cast": "本人 / 合作方",
    "desc": "由版权方提供，授权范围：本机播放，不含二次分发。",
    "color": "#4C7FD1",
    "accent": "#17335C",
    "sources": [
      { "label": "主源", "url": "https://example.com/demo/master.m3u8" },
      { "label": "备用", "url": "https://example.com/demo/backup.mp4" }
    ]
  }
]
```

## 五、内置片库的许可说明（事实）

内置条目全部为开放许可内容，来源与许可写在各自 `desc` / `subtitle` 中：

- 大雄兔（完整版，249 MB）· W3C 官方镜像 · CC-BY 4.0
- 钢铁之泪（完整 720P，372 MB，MOV/H.264）· Blender 官方 · CC-BY 3.0
- 辛特尔（官方预告，4.3 MB）· W3C 镜像 / Blender 官方 · CC-BY（完整版仅 MKV，浏览器不可流播，故不内置）
- 其余为公开测试流（BipBop、PTS、水母等），只用于验证播放链路，不声称是影视内容。

`archive.org`、`commons.wikimedia.org` 在本机网络下不可达，因此没有内置，也不会在界面上假装提供。
