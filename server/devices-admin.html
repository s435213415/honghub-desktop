能力表说明

caps 六键：sdk（系统 API 版本，不是 0/1）· fullscreen（全屏是否生效）· hideBars（系统栏是否隐藏）· avoidArea（安全区是否实时注入）· orientation（能否锁横竖屏）· backKey（返回键是否被接管）。 值为 1 表示可用，0 表示该能力降级（网页侧会自动走兜底逻辑）。
